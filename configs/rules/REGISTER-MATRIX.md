# 真语料矩阵校验（扩展版）

## 语料

| 类别 | 源 | 字数级 | 用途 |
|---|---|---|---|
| literature | 鲁迅《故乡》、余华《河边的错误》、钱钟书《围城》ch1、老舍《骆驼祥子》ch2 | 1k–15k | 文学修辞误报（拟合过头） |
| prose | 朱自清《背影》 | 1.3k | 非小说散文鲁棒性 |
| classical | 《红楼梦》第一回 | 7.8k | 文白半文 register |
| lightnovel | 彩云国物语 | 2k | 日式翻译腔误伤 |
| webnovel | 明朝那些事儿 ch1、鬼吹灯 ch1、天龙八部 ch1 | 2k–23k | 网文范式（三个子类） |
| ai | novel/novel1/drafts 42 章 | — | 真阳性锚点（用户确认 AI 写） |

跑法：`sentinel audit-draft <file> --no-corpus-learning --format json`，取 `hard_flags`，
按 `count / chars * 10000` 归一（或规则自带 `per_10k`），人写取类别均值、AI 取章均值。

## 结论：三类规则

### A. 真阳性（AI 远超人写，保留）

| 规则 | 人写 | AI | 说明 |
|---|---|---|---|
| sentence_lengths:短句密度 | 64.7 | 201.8 | AI 正文节奏最稳的判别特征 |
| sentence_lengths:短句连发 | 11.3 | 31.0 | |
| ba_operation_contexts:动作操作 | 14.1 | 41.1 | 把字句操作日志化 |
| ba_operation_contexts:情绪动作 | 1.3 | 11.9 | |
| battle_profile:动作链缺结果 | 8.7 | 32.4 | |
| custom_templates:一A就B | 16.4 | 17.6 | 比值≈1，仍有判别力（绝对量都高） |

### B. 语域误报（人写高频、AI 零命中，已标 register）

按「命中的人写类别数」机械标注：1 类→该类别；2–3 类→逗号列表；≥4 类→`common`。
prose 归并 literary。

- `common`（各人类语域通用）：不、是、因为、可是、！、：、？
- `literary`：却、只是、所以、仿佛、像是(tokens/phrases)、是、慢慢、越来越、几乎没有、
  像/活像模板、定语模板 modifiers
- `literary,lightnovel`：……、——
- `lightnovel`：？！/！？
- `webnovel`：而是、不是因为、没有A也没有B、肯定后否定
- `literary,webnovel`：不是、于是、像……一样、问题在于/这就是
- `literary,lightnovel,webnovel`：然后、不是A而是B、否定后肯定

修正 PR #9 两处过窄标注：`不`（literary→common，散文 211/网文 161/古典 160 也命中）、
`然后`（colloquial→三类别，文学 33.8 才是最高）。

### C. 噪声源（learned 项，逐源自学习，跨源不可比）

`aa_bb_patterns:*`（短分句排比 60+ 变体）、`clause_prefixes:*`、`short_phrases:*`、
`sentence_patterns:*` 按当前单篇文本学习，规则名带文本专有名（「段誉道」「方先生」），
天然只在本篇内可比。矩阵里它们在人写文本成片出现（天龙 23k 字→472 条），
说明这类规则对长人写文本噪声最大，但跨源统计无意义——留作后续专门评估。

## 未动的规则

`judgement_contexts`、`fatigue_windows`、`subject_leads`、`dialogue_*`、`custom_templates` 等
profile/metric 类规则人写≈AI（比值 0.3–1.6），判别力中性，不标 register。
